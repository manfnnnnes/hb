# С днём рождения, Настюша

Личный сайт-сюрприз.  
**Next.js 14 (App Router) + TypeScript + Tailwind CSS + Framer Motion**

## Что улучшено в этой версии

- Чуть более светлая и тёплая палитра
- Более красивая и длинная анимация открытия конверта (3D-клапан, лента, свечение, выезжающее письмо)
- 6 эмоциональных карточек вместо 5
- Улучшенный текст письма
- Тихая фоновая музыка с кнопкой включения/выключения (появляется после открытия)
- Всё по-прежнему максимально просто деплоится на Vercel

## Как задеплоить на Vercel (без настроек)

1. Создай новый пустой репозиторий на GitHub.
2. Залей туда все файлы этого проекта.
3. Зайди на [vercel.com](https://vercel.com) → New Project → выбери репозиторий → Deploy.
4. Через минуту сайт будет готов.

Можно также просто перетащить папку проекта на [vercel.com/new](https://vercel.com/new).

## Как редактировать тексты

Все тексты находятся в одном файле:

```
content/site-content.ts
```

Правильные ответы на вопросы — там же, в объекте `answers`.

## Музыка

1. Положи свой трек в папку `public` с именем **`music.mp3`** (или `.ogg`).
2. После открытия письма в правом нижнем углу появится кнопка 🎵 — ею можно включать/выключать музыку.
3. Если файла нет, сайт просто работает без звука (ошибки не будет).

Рекомендую тихий фортепианный или ambient-трек, громкость уже выставлена мягко (~28%).

## Как заменить фото-заглушки

1. Положи свои фото в `public/` (например `photo-1.jpg`, `photo-2.jpg`).
2. Открой `components/MainContent.tsx` и замени блоки `PhotoFrame` на обычные `<img>`, сохранив стили рамки, либо попроси помочь.

## Локальный запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000
