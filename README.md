# С днём рождения, Настюша

Личный сайт сюрприз. Next.js 14 (App Router) + TypeScript + Tailwind CSS + Framer Motion.

## Как задеплоить на Vercel (без настроек)

1. Создай новый пустой репозиторий на GitHub.
2. Залей туда все файлы этого проекта:
   ```bash
   git init
   git add .
   git commit -m "первый коммит"
   git branch -M main
   git remote add origin ССЫЛКА_НА_ТВОЙ_РЕПОЗИТОРИЙ
   git push -u origin main
   ```
3. Зайди на [vercel.com](https://vercel.com), нажми "New Project", выбери этот репозиторий.
4. Vercel сам определит что это Next.js проект. Ничего менять не нужно, просто нажми "Deploy".
5. Через минуту сайт будет доступен по ссылке вида `твой-проект.vercel.app`.

Можно также перетащить папку проекта прямо на [vercel.com/new](https://vercel.com/new) без GitHub, если так удобнее.

## Мини-игра на секретке

Пока конверт закрыт, на экране падают лепестки, которые можно ловить кликом или тапом. Каждые 5 пойманных лепестков появляется тёплая фраза-награда. Счётчик и сами фразы редактируются в `content/site-content.ts`, в объекте `comingSoon` (поля `gameHint`, `gameLabel`, `catchRewards`).

## Секретка до дня рождения

До 13 ноября сайт показывает всем закрытый экран с обратным отсчётом, никакого доступа к вопросам или письму нет.

Чтобы самому заглянуть и всё проверить раньше срока, открой сайт с приставкой `?preview=true`, например:

```
https://твой-сайт.vercel.app/?preview=true
```

Это включает предпросмотр только в твоём браузере по этой ссылке, для всех остальных, кто откроет обычную ссылку, сайт останется закрытым до даты.

Чтобы поменять саму дату открытия, открой `app/page.tsx` и поменяй строку:

```ts
const REVEAL_DATE = new Date("2026-11-13T00:00:00");
```

Текст на экране секретки (заголовок, подпись, подписи под цифрами) редактируется в `content/site-content.ts`, в объекте `comingSoon`.

## Как редактировать тексты

Все тексты сайта (вопросы, письмо, карточки, подписи) находятся в одном файле:

```
content/site-content.ts
```

Открой его и меняй любые строки, ничего в остальном коде трогать не нужно.

Правильные ответы на вопросы находятся там же, в объекте `answers`, в начале файла.

## Как заменить фото заглушки на настоящие

Сейчас в блоке "Наши моменты" стоят декоративные заглушки (`components/PhotoFrame.tsx`). Чтобы вставить настоящие фото:

1. Положи свои фото в папку `public`, например `public/photo-1.jpg` и `public/photo-2.jpg`.
2. Открой `components/MainContent.tsx`, найди блок с `PhotoFrame` и замени его на обычный `<img src="/photo-1.jpg" ... />` с нужными стилями, либо попроси помочь это сделать аккуратно с сохранением стиля рамки.
